# Эксплуатация, стоимость и восстановление

[English](operations.en.md)

## Лимиты и размещение

D-15: сервер не дороже $40/месяц в Германии, Нидерландах или Болгарии; OpenAI отдельно до $50/месяц. Платные внешние источники не согласованы. Исходная нагрузка — сотни операций/месяц; количество страниц чеков, длина чатов и backfill измеряются отдельно.

Целевой профиль для проверки: один VPS, Go API/worker, PostgreSQL, web/reverse proxy и один последовательный collector. RAM/CPU/disk выбираются по измерению. Сумма сервера включает обязательные IP, диск и налоги, конвертируется в USD на дату оценки. Сейчас тариф не выбран, приобретений нет; task-0.9 должен подтвердить достижимость и смету. Доступность облачного региона сама по себе не доказывает доступность банков и OpenAI.

## OpenAI

Срез официальной Standard short-context цены на 2026-09-06, USD за 1M токенов:

| Кандидат | Input | Output |
| --- | --- | --- |
| GPT-5.6 Luna | 0.20 | 1.20 |
| GPT-5.6 Terra | 2.00 | 12.00 |

Это кандидаты для eval, не утверждённая конфигурация. Vision, reasoning/output, повторные попытки, cache writes, длинный контекст, tier и платные tools требуют отдельного учёта. Сверять цены перед выбором/запуском; доступность модели в аккаунте не проверена. [Официальные цены](https://developers.openai.com/api/docs/pricing), [модели](https://developers.openai.com/api/docs/models).

Пример только для масштаба: 1 000 вызовов Luna по 2 000 uncached input и 500 output токенов стоят $1.00 по указанной таблице. Это арифметическая оценка текстовых токенов, не обещание стоимости полного приложения. task-0.8 измеряет реальные calls/tokens/pages и повторы, затем фиксирует модельный routing, максимальные размеры и денежные резервы.

Бюджет приложения учитывает actual + reserved in-flight + unknown-outcome стоимость. Перед вызовом транзакционно резервируется консервативный максимум с ограниченным output/context/tools; модель не выбирает себе неограниченный compute. Неизвестный счёт не освобождает резерв. Период AI-cost — календарный месяц UTC; незавершённые/неопределённые списания не стираются на смене месяца и сверяются с месяцем фактического биллинга. При недостатке лимита задача ждёт, обычный учёт работает. Пользователь не давал разрешения автоматически увеличивать $50.

Разрешены полные операции и чеки без секретов. API-данные по умолчанию не используются для обучения без opt-in; стандартный abuse monitoring может сохранять содержимое до 30 дней с указанными в политике исключениями. Responses application state имеет собственные правила: запросить `store=false`, хранить историю чата у себя и не считать это гарантией Zero Data Retention. ZDR требует отдельной доступности/одобрения; она не заявляется для пилота. Не загружать файлы в долгоживущие provider stores без необходимости, удалять временные provider file objects после использования по их контракту. [Data controls](https://developers.openai.com/api/docs/guides/your-data).

## Копии на MacBook

Копирование инициируется локальным Mac по исходящему соединению; доступность Mac — условие, не обещание круглосуточной работы. Сервер формирует согласованный набор: snapshot БД, inventory неизменяемых вложений и manifest с версиями/временем/checksum. Набор считается успешным только после проверки всех частей локальным получателем.

Копия зашифрована; приватный recovery-ключ хранится отдельно от единственной копии и от аварийного сервера. Server/master keys и recovery-коды доступа не публикуются и не печатаются. Внешняя облачная копия не включена в согласованный MVP.

При недоступном Mac показывать возраст последнего полного набора и реальное окно возможной потери. Часовой RPO условен доступностью и успешным завершением цикла; прерванный download не обновляет success timestamp. После восстановления связи продолжить копирование, сохранив последний исправный набор. Политика количества/срока хранения и дисковый лимит Mac закрываются task-0.9 до автоматического удаления каких-либо старых наборов; текущий пакет не разрешает такое удаление.

В изолированной rehearsal восстановить DB/attachments/schema, проверить балансы, аудит, identities и jobs, замерить цель RTO до четырёх часов. Старые bank sessions и web sessions не оживлять автоматически. Проверить unknown AI charges перед повторами. Runtime восстановление и сохранность настоящих данных этим документом не доказаны.

## Наблюдение и уведомления

Состояния источников: connected/reauth_required/syncing/stale/partial/failed/disconnected. AI: pending/running/reviewed/clarification/waiting_budget/failed/superseded. Backup: pending/complete/stale/failed. Объединение этих статусов в один зелёный индикатор недопустимо.

Сводки и напоминания имеют source event ID, время/таймзону и dedup key. Push-подписка привязана к устройству/owner, при recovery или отзыве устройства инвалидируется. Payload по умолчанию не показывает суммы/названия продавцов на экране блокировки. In-app канал работает при отсутствии разрешения на push. Реальное разрешение/запрет, доставка и отзыв push проверяются в Chrome и Arc на macOS. Установка приложения не требуется контрактом; неподдерживаемая доставка оставляет in-app канал и явный статус.

## Доказательства запуска

Для допуска полного MVP нужны: все AC; полный readback каждого продукта шести платформ; измеренный AI quality/cost; отсутствие двойных финансовых эффектов при retries; приватность/авторизация; RU/EN/desktop; push в реальных Chrome и Arc на macOS; backup/restore rehearsal и фактическая смета. CI и mocks не заменяют эти проверки. Развёртывание и любое приобретение ресурсов требуют действующей авторизации отдельного этапа.

## Семейная эксплуатация

Лимиты $40/$50 и сотни операций относятся к семье целиком. AI accounting/reservations привязаны к family budget, а не выделяют $50 каждому. Копии включают обоих пользователей, членство, принадлежность, allocation revisions, общий чат и авторство. Восстановление входа отзывает только устройства соответствующего пользователя; сброс второго входа не разрешён.
