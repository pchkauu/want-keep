# Компоненты Want Keep

[English](design-components.en.md) · [Дизайн](design.md) · [task-7.11](tasks/task-7.11.md)

## Назначение и владение

`web/src/design-system/components/` содержит исходники визуальных компонентов. Они адаптированы по проверенным шаблонам shadcn 4.21.0, `base-nova`, с использованием Base UI 1.8.0. Это принадлежащий проекту код, а не файлы, которые следует перезаписывать генерацией. Перед обновлением применять CLI `add --dry-run`/`--view` и проверять изменения контрактов и зависимостей.

Интерактивный каталог `/__design/components` содержит только синтетические данные. Его код, композиции и стили отсутствуют в production bundle. Переиспользуемые компоненты доступны продуктовым features; демонстрационные обработчики — нет. Каталог не обращается к финансовым API, не сохраняет данные в browser storage и не реализует учёт или восстановление доступа.

Уточнение пользователя для #58: формы и композиция нового референса, палитра Want Keep. Крупная акцентная поверхность, боковые action tiles, вложенные строки и профильная поверхность адаптированы к desktop. Радиусы: поля/обычные кнопки 12 px, панели 24 px, крупные поверхности 32 px, badges — pill. Это заменяет прежние 2/4/8 px, сохраняя исходные цвета и шрифты. Обводки, мобильная нижняя навигация и платёжные действия из референса не входят в результат.

Для адаптированных фрагментов shadcn сохранена MIT-лицензия в `web/src/design-system/components/LICENSE.shadcn`. Исходники registry просмотрены до адаптации; источником реализации служит код проекта.

## Публичные интерфейсы

| Семейство | Контракт |
| --- | --- |
| Button / ActionTile | Событие передаётся вызывающему коду. Обычный Button имеет `type=button`; submit выбирается явно. `disabled` и `aria-busy` — отдельные свойства. Для ссылок используется Base UI `render`/`nativeButton=false`. |
| Input / Textarea / MoneyField | Управляемая строка; MoneyField не использует Number/float/округление и не обрезает длину. `assetLabel` — подпись. Вызывающая форма задаёт ошибки и допустимость ввода. Полная длинная сумма доступна в раскрываемом образце. |
| Field / Form | Base UI связывает label, description, error и контрол. Textarea использует явный `htmlFor/id`. Состояние отправки и прикладная валидация принадлежат форме-потребителю. |
| DateField | `value` — `YYYY-MM-DD` или null; необязательный `draft` сохраняет исходный текст. `onChange` возвращает `{draft, value}`: undefined означает невалидный текст, null — пусто, строка — существующая дата. Потребитель сохраняет draft и не отправляет undefined. RU `ДД.ММ.ГГГГ`, EN `MM/DD/YYYY`; Gregorian, понедельник. |
| Calendar | Обёртка DayPicker. Преобразование JS Date в календарную строку принадлежит CalendarDate; без `toISOString` и сдвига часового пояса. Выбор даты через popover возвращает фокус к его кнопке. |
| Select / Combobox | Строковый ID, явные options, подписи и callback. Combobox ищет среди переданных options; сетевой поиск принадлежит feature. |
| Checkbox / Radio / Switch / Toggle | Состояния и клавиатурное поведение Base UI; подпись обязательна в потребителе. Фокус не заменяет selected/checked семантику. |
| Dialog / AlertDialog / Sheet | Заголовок и описание обязательны. Modal focus trap, Escape, возврат фокуса; sheet использует ту же dialog-границу. Подтверждение решения реализует потребитель. |
| Popover / Tooltip / Toast | Короткая контекстная информация. Tooltip не заменяет подпись. Toast через Base UI, максимум три, 8 секунд; важный результат остаётся постоянным сообщением. Все подписи закрытия передаются локализованными. |
| Sidebar / Tabs | Desktop-навигация; Sidebar получает явные ссылки/currentId. Не определяет пользователя, права или доступность данных. Tabs использует roving focus Base UI. |
| Table / Pagination | Семантическая таблица в подписанной области прокрутки. Pagination получает доступность направлений, summary и callbacks; не вычисляет серверное количество строк или финансовую сортировку. |
| Surface / Avatar / ListItem | Заполняемые поверхности, fallback инициалов, вложенные строки. Изображения и данные приходят от потребителя. Нет встроенного доступа к профилям или внешним источникам. |
| Badge / Alert / Empty / Skeleton | Текст объясняет состояние независимо от цвета. Alert объявляет изменение только по явному `announce`; скелетон не показывает нулевые суммы. |
| Progress / ChartLegend | Progress получает готовый процент или null. Легенда получает готовые подписи значений и callbacks видимости; маркеры различаются формой. Расчёты и графики принадлежат аналитике. |
| ChatResult | Автор, статус, объяснение, details/actions — явные presentation props. Не интерпретирует ответ AI, не назначает финансовый результат и не исполняет команду. |

## Состояния и доступность

Каталог показывает все UISTATE-01–17. Применимые состояния проверяются у владельцев: disabled/loading у действия, invalid у поля, selected у выбора, error/unknown/conflict у демонстрационной формы. Не создаётся общий финансовый state machine внутри примитивов.

Unknown сохраняет черновик и не разрешает повторную отправку; демонстрационная проверка исходной команды явно переводит образец в confirmed. Conflict показывает сохранённую и введённую версии. Session expiry скрывает синтетический черновик. Эти примеры проверяют визуальное поведение; серверные гарантии остаются task-1.3 и feature-задачам.

Границы компонентов не содержат generated DTO, API-клиентов и feature-кода. Клавиатурный фокус инвертирует заливку и текст, включая error/selected/hover. Шрифты локальные. Reduced motion обнуляет обычные переходы; MOT-01–05 остаются task-7.15. Каталог не доказывает полное соответствие WCAG или AC-102.

Допустимый интервал календаря — 0001-01-01…9999-12-31. Навигация, выбор и CalendarDate.fromDate проверяют границы; конвертация отклоняет даты до нашей эры, вне диапазона и невалидные даты. Avatar предоставляет заданное имя через семантику изображения, в том числе при ошибке загрузки. Неизвестный прогресс показывает статичный нейтральный узор без заполнения завершённого состояния; description задаёт локализованное доступное значение. Владелец языка каталога устанавливает язык документа для порталов и возвращает прежний при размонтировании.

## Проверки и передача

`make test-web FILTER=design-components`, `make e2e SCENARIO=design-components`, регрессия `design-tokens`, `make check`, `git diff --check`. Реальный Chrome проверяется отдельно от Chromium; по решению пользователя Arc остаётся последующей приёмке. Контрольные окна 1280×720/1440×900, масштаб 100%/200%.

Task-7.1 и другие экранные задачи используют эти примитивы и владеют view models, прикладными состояниями и восстановлением исхода команд. При смене языка вызывающая форма форматирует корректное календарное значение и сохраняет некорректный черновик для исправления. Task-7.12 проверяет desktop UX и визуальную приёмку; task-7.13 реализует экраны подключений; task-7.14 — настройки и состояние учёта; task-7.15 — событийные анимации. [Доказательства реализации](evidence/task-7.11-components.md).
