# Словарь

[English](glossary.en.md)

| Термин | Значение и граница |
| --- | --- |
| User / Member | Отдельная личность входа / её членство и роль в семье. |
| Household | Общая область финансов и доступа участников; лимит состава задаётся конфигурацией. |
| Owner / Actor | Принадлежность конкретного ресурса / пользователь или system principal, совершивший действие; независимые признаки. |
| Allocation | Распределение одной суммы по участникам; не отдельный денежный платёж. |
| Reimbursement | Явный взаимный долг и его погашение; исключены из семейного капитала. |
| Connection | Подключение аккаунта платформы, его способ чтения, capability и состояние сессии. Не финансовый счёт. |
| Account | Собственный счёт одного актива и назначения; может быть наличным, банковским, кредитным или криптовалютным. |
| Card | Средство доступа к счёту; отдельная карта не обязательно означает отдельный остаток. |
| Asset | RUB, USD, USDT или BTC. USDT-сеть — атрибут операции/адреса, а не новая валюта. |
| Money | Точная десятичная сумма с активом. Форматирование и конвертация не меняют исходное значение. |
| SourceRecord | Неизменяемое полученное доказательство с источником, namespace ID и версией/временем; не готовое бизнес-решение. |
| Transaction | Одна экономическая операция с типом, статусом, денежными сторонами и доказательствами. |
| Posting | Изменение счёта внутри атомарной операции; не каждая проводка является расходом. |
| Opening balance | Начальная точка выбранного периода; не доход. |
| BalanceSnapshot | Состояние, сообщённое источником в определённый момент; сверяется с журналом, не скрывает его расхождения. |
| Pending / Posted | Ожидающее подтверждения / проведённое движение. Hold влияет на доступность, не равен фактическому расходу. |
| Transfer / Exchange | Перемещение собственных денег / конвертация с двумя валютными сторонами. Основная сумма не потребительский расход. |
| Fee / Funding | Комиссия / периодический торговый платёж. Знак и включение в net P&L определяются контрактом источника. |
| Refund | Возврат с реальной датой поступления и связью с исходным расходом/позицией. |
| Reconciliation | Сверка сопоставимых по времени остатков, операций и покрытия с объяснимым расхождением. |
| Category / Merchant / Item | Вид расхода / продавец / позиция чека. Независимые измерения аналитики. |
| Obligation | Плановый платёж по дате; сам не создаёт фактическую операцию. |
| Flexible allocation | Месячный лимит переменных трат категории в одной валюте. |
| Expected income | Планируемое поступление с датой; не полученные деньги до подтверждения факта. |
| Goal reservation | Однократное выделение собственных денег на цель, ограничивающее доступность без внешнего перевода. |
| Available allowance | Лимит, обеспеченный уже доступными собственными средствами соответствующей валюты. |
| Forecast allowance | Сценарий с ожидаемыми поступлениями и платежами по датам; не обещание доступности денег. |
| Coverage | Границы, полнота и свежесть данных/оценки; partial и unknown — значимые состояния. |
| AI proposal / Clarification | Предложение разрешённой команды / запрос недостающего факта. Ответ модели сам по себе не является проводкой. |
| AI review revision | Проверка конкретной версии операции; устаревший ответ не применяется к новой версии. |
| XIRR | Годовая денежно-взвешенная доходность по датам внешних потоков и конечной оценке; не договорная ставка и не гарантия будущего дохода. |
| RPO / RTO | Фактическое окно потенциальной потери данных / время восстановления. RPO копий на Mac условен его доступностью. |
| REQ / AC / task | Проверяемое требование / наблюдаемый критерий / задача с зависимостями и доказательством результата. |
| Ready | Вердикт достаточности спецификации/плана. Не означает успешный runtime и не выдаёт разрешение на deployment. |
