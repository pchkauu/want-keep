# Task-7.11: компоненты Want Keep

[English](task-7.11-components.en.md) · [Контракты](../design-components.md) · [Issue #58](https://github.com/pchkauu/want-keep/issues/58)

## Результат

Реализованы принадлежащие design-system компоненты на Base UI и интерактивный RU/EN-каталог `/__design/components`. Новый референс определяет округлые формы, акцентную поверхность, боковые действия, вложенную историю и профиль; по решению пользователя палитра и шрифты Want Keep сохранены. Радиусы обновлены согласованно в CSS и RU/EN-контракте. Шрифты и логотип не изменялись.

Компоненты принимают presentation props и callbacks. Денежные строки не преобразуются в Number; ручные даты сохраняют невалидный черновик, календарь работает с Gregorian date без UTC. Предусмотрены все 17 демонстрационных UISTATE, вложенный календарь/select в диалоге, восстановление фокуса, неизвестный исход, конфликт и постоянное подтверждение. Форма защищена от повторного демонстрационного submit.

Каталог и его стили исключены из production bundle. shadcn-алиасы ведут к владельцу design-system, шаблоны проверены через закреплённый CLI, MIT notice сохранён. Зависимости добавлены только из согласованного набора. Backend, API, миграции и production не изменялись.

При первоначальной проверке исправлены очистка выбранной даты повторным выбором и скрытая для средств доступности кнопка закрытия toast. Поведение tabs проверяется по Base UI: стрелки перемещают фокус, Enter выбирает. Смена языка форматирует валидную дату и сохраняет ошибочный черновик. Ограничения sandbox на локальный порт и Go cache устранены запуском разрешённых проверок с нужным доступом; это не продуктовые отказы.

В первом раунде независимо подтверждены четыре замечания: границы лет календаря, доступные имена аватаров, неизвестный прогресс и язык порталов. Исправления покрыты unit- и браузерными регрессиями. В граничном тесте locator уточнён до textbox: закрывающийся popover имел ту же подпись. Затронутые проверки повторены; пройденные неизменённые сценарии токенов сохраняют силу. В реальном Chrome дополнительно подтверждены русский язык порталов и локализованный неизвестный прогресс. Опубликованные исправления проходят новый раунд Avida.

## Граница доказательств

AC-096 подтверждён в объёме каталога. AC-094/095/099/101 подтверждены в описанной части компонентов и демонстраций. Реальный Chrome и автоматический Chromium учтены отдельно; контрольные окна не выдаются за физический resize Chrome. Arc отложен по решению пользователя. Продуктовые экраны, серверное восстановление команд, реальные источники, AI-вызовы, анимации финансовых событий и полная WCAG/MVP-приёмка здесь не проверялись. SDD остаётся Ready for development, эксплуатационная готовность не заявляется.

Self review, CI публикуемого кандидата и merge подтверждаются отдельно ссылками в PR и issue; локальная проверка их не заменяет.
